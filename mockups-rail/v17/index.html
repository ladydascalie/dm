It is one colour on every row, whatever the state, so the decoration is a socket rather than a second signal. The glyph keeps its own state colour on top, and the empty cells stay empty.

22 rows. The margin reads as a column of small identical sockets, each holding one coloured glyph. A red glyph is loud because the socket is dull, not because the cell is red.

One colour, from the palette. #21202d is the rail's hover ground, so the decoration introduces no new colour and a theme that repaints the rail repaints the socket with it.

Empty stays empty. A pane that has not reported and a row with nothing waiting paint no socket at all, so a gap in the column is information too.

The focus ground, the hover ground, and the chip ground the hint bar uses. The middle one is drawn above: distinct from the row without becoming a stripe.

What this decoration is

  • A socket, not a status. One ground for every state, so colour never comes from the cell, only from the glyph in it.
  • One cell, one colour, one radius. Same width as the glyph it already held; nothing moves.
  • Rounded by two pixels in this drawing, which a terminal cell cannot do. In dm it is a plain filled cell, so read the shape as square.
  • The git mark stays bare. A target, not a state; it gets no ground.
