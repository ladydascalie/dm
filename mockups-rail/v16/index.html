One cell of decoration, on the cell that already means something. The state mark keeps its full colour and gains a ground mixed from that same colour at 18 percent over the row's own background, so a focused row composites correctly and a hovered row does not wash it out. The margin becomes a column of quiet colour you can find without reading a glyph. No other cell is decorated.

22 rows. Working rows carry a faint amber cell, a done row a faint green, a blocked row a faint red, an idle row a faint cyan. Unknown stays empty, and so does a clean window with nothing waiting.

Why 18 percent: high enough to read as a colour at a glance, low enough that a column of working rows stays quiet and a single red one still stands out. The glyph carries the exact state; the ground carries the tone.

Rollups are decorated too. A workspace or project row shows its worst state in the same cell with the same ground, so the margin is one continuous strip of tone from project to pane.

Ten, eighteen, twenty eight percent. Ten is nearly invisible on a dark theme, twenty eight competes with the red that should stand out. Eighteen is the one drawn above.

What the decoration is, and is not

  • It is one cell. Same width as the state glyph it already holds; nothing moves.
  • It is the state colour, diluted. No new colour enters the palette, and a theme that changes its state colours changes the ground with them.
  • It is not a second signal. The ground never says anything the glyph does not; it makes the glyph findable at a glance.
  • The git mark is not decorated. It is a target, not a state, and a second kind of tint would blur the one rule the margin has.
