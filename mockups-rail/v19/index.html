What transfers, and what cannot

  • Colour means state. The agent mark goes neutral, so the state cell is the only coloured cell in the thin rail, exactly as the margin is the only coloured cell in the full one. Two amber cells became one, and a red row is now unmistakable at this size.
  • Unknown is silent. The question mark goes, so a pane that has not reported looks like a pane with nothing to say. A gap in a four cell column is louder than a glyph that means "no glyph".
  • The mark before the state stays. Bar, mark, state, then the badge in the fourth cell when a question is waiting. Nothing moves.
  • What cannot transfer. The git field has no room, and git is a window fact while a thin rail row is a pane. If you want git in the thin rail it would have to be a tint or a glyph sharing the state cell, which is the one thing you have twice rejected. I left it out.
  • The shell keeps its terminal icon. A shell has no state to report, so if its mark went blank the row would be two empty cells and the blur would say nothing at all.

The one open question

Should a focused pane's mark brighten to rail text, the way the full rail's focused name does? Today the mark is the state colour on every row, so focus is invisible in the thin rail except for the hover ground. Brightening it costs no cell and gives the thin rail the same "where am I" cue the full one has. Say yes and it goes in the same change.
