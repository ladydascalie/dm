dm rail · v2 · the proposal

v1 measured what is busy. This is what I would change, drawn the same way: same grid, same glyphs, same 40 cells, so a row can be compared against v1 cell for cell. Three changes to the content, one to the type, and one lever deliberately left out.

The changes, in one list

  • A. Drop what restates the tree. No clean, no workspace or project count unless the row is folded, no workspace bullet, no pane dot.
  • B. One icon per pane. The state mark keeps column 7; the agent mark goes; the pane name starts at column 10 instead of 11 and the dot after it goes.
  • C. A label elides its shared prefix before it elides its tail. A window under durability-and-flakes whose folder also starts with it reads w10 …-w1, and only when the row would otherwise not fit.
  • E. The project name is not bold. Weight is reserved for the level you act on: the workspace. The accent colour already says "project".
  • Not taken: collapsed windows. Drawn at the end so you can see the alternative, not applied.

6. Not taken: collapsed windows

The biggest row saving is hiding the panes of every window except the active one. I am not proposing it against these changes, because it changes how the rail is read rather than how much ink it spends, and it makes one more click necessary. Drawn here so the choice is visible.

What it buys: twelve fewer rows in this fixture. What it costs: a pane's name is one click away, and the pips have to carry four states in three cells. My recommendation is to take v2 first, live with it for a week, and only then ask whether the rows still feel long.

7. What I need from you

  • Lever C, the elided prefix. Take it or drop it. It is the only change here that removes information rather than ink.
  • Lever E, the project name's weight. If the accent alone does not read as "project", the fallback is to indent workspaces by two, at a cost of two cells on every workspace row.
  • Anything in v1 you want kept that v2 dropped: the bullet, the pane dot, or the workspace count when unfolded.
