dm rail · v1 · drawn from the painter, not from memory

Every row is composed the way rail.RailRow composes it, with the built-in theme and the nerd glyph set: a project bar in column 0 on every row, the caret in column 1 for a project or workspace and column 3 for a window, the agent mark in column 7 and the state in column 9 of a pane row, the right run ending at column 38, and column 39 left for the grip strip. The rail is drawn at 40 cells, 39 of them content, because that is what your screenshots show: a full window label, its git stats and the mark all on one row. The default rail is 34, and section 7 shows what the elision ladder does there.

Fixture: the session from your screenshots. Project dm with workspaces main, durability-and-flakes and suite-tail, project console, project lb-key-dot, and one shelved pane. Glyphs are the nerd set: π for a pi agent, a terminal icon for a shell, gear for working, check for done, warning for blocked, question for unknown, and the nerd git icon for the mark.

Two levels, one shape. A project row and a workspace row are both bar, caret, space, bold name, right number. The only differences are the name's colour and the bullet. That is the complexity you feel: the levels cannot be told apart without reading them.

The cost. A shell and an idle agent would look the same, so the shell state carries it: a triangle for a shell, the gear, check, warning or circle for an agent. If you would rather keep the agent mark and drop the state on idle panes, that is the other trade and one line either way.

8. Open questions

  • Lever C is a taste call. The ellipsis prefix saves the most cells and costs a small lookup. If you would rather keep the full folder, say so and I drop it.
  • Lever B needs your call on shells. One state mark that also means shell, or keep the agent mark and drop only the dot.
  • Should the project row exist at all when a session has one project? Not in this fixture, but a single-project session pays a row and a caret for nothing.
  • Lever D, not drawn yet: collapse the panes of every window except the active one. That is the biggest row saving and the biggest behaviour change. Say if you want it in the next version.
