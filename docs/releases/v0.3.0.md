dm 0.3.0 makes the phone page hold still, stops the phone URL from changing,
and gives the shelf float the mouse.

Nothing a caller passes breaks in this release, though below 1.0.0 a minor may
change behaviour. The page keeps no second skin: the `tui` switch, the `?skin`
link and the keys that stored an answer are gone, and the terminal look is the
page.

## The phone page holds still

An installed page on iOS got a viewport one status bar shorter than the screen,
top aligned, so it never reached the bottom of the phone. The composer floated
93 points above the bottom edge with dead screen under it, and the translucent
status bar painted a scrim over the page's top padding.

- The app asks for an opaque status bar. The page now starts below the bar and
  its viewport ends at the bottom of the phone, so the composer clears the home
  indicator and nothing floats.
- The grey band across the top is gone with the translucent bar.
- The page carries one look. The `tui` switch, the head script that restored it
  before the first paint and the blunt corner sweep went, and so did the
  rounded corners the sweep existed to erase. The running spinner keeps its
  circle.
- The chosen view tab painted an accent label on the working-blue fill. It
  paints dark on the fill now.
- The actions sheet carries `reload the page` at its foot. An installed app has
  no reload button and no address bar, and the server sends the page and its
  script with no cache, so that tap is the whole way a new build arrives.

iOS reads the status bar style when the icon is added, not on load. An icon
added before this release keeps the translucent bar, so delete it and add the
page to the home screen again once.

## The phone URL stops changing

The token rotated whenever the session directory was new, so a bookmarked URL
answered 401 and an installed app had nowhere to paste another one.

- `web-token` in `config.kdl` pins the token. An explicit `--token` wins, then
  the node, then the session's `web.token`, and `dm web` prints which one
  decided.
- The pairing cookie lasts 400 days, so bookmark the bare address. The token
  appears once, on the first visit.
- A page that a rotated token locked out answers the next `GET /` with a field
  for the current token.

## The shelf float takes the pointer

Mode `shelf` dropped every parsed mouse event, and a click on the float found
the live pane behind it.

- A chip selects its member on the cells the paint put the chip in, so a narrow
  shelf keeps its painted chips and answers nothing past them.
- A press outside the box closes the float and is spent on it. The members stay
  shelved and keep running.
- A left press on the member's screen selects, and the drag copies through
  OSC 52. The selection agrees with the body rect the float draws.
- A right press opens the shelf's own menu: next, previous, pop and close. A
  shelved pane has no rect, so the pane menu's split, scrollback and layout
  moves cannot act on it.

## Also

- The alternate-screen scroll refusal now reads `program owns the screen: scroll
  in it`, which names the way out inside a toast that would otherwise elide the
  instruction.

## Documentation

- The manual page, `dm llms` and `dm html` cover drag to copy, the shell marks
  and the terminal's own selection bypass: Shift on most terminals, Option on
  iTerm2.
- The README documents `web-token`, the 400-day cookie, the sheet's reload row
  and the page's single look.

## Updating

```sh
dm upgrade
```

A session that is already running keeps the old binary until it restarts.
Re-add the home screen icon once, for the status bar.
